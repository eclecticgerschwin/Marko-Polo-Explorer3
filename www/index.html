User Guide & Setup

How to Install and Use Marko Polo Explorer

1

Download & Open DMG Installer

Download MarkoPoloExplorer.dmg (or MAC.zip). Double-click the .dmg disk image file to open the installation window.

2

Drag to /Applications Folder

In the installer window, drag the Marko Polo Explorer v1.0.app icon directly into your Applications folder shortcut.

3

macOS Privacy & Security Authorization

On first launch, if macOS Gatekeeper displays a security prompt:

  • Go to System Settings ➔ Privacy & Security.
  • Scroll down to the Security section and click "Open Anyway".
  • Alternatively, right-click (or Control-click) the app icon in Finder and select Open.
xattr -cr "Marko Polo Explorer v1.0.app"
4

Connect iPhone & Start Exploring

Connect your iPhone via Lightning/USB cable and tap "Trust This Computer". Select your iPhone from the left panel dropdown to browse photo libraries!
